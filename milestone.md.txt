## Important Decisions

- This is a complete admin-controlled auction website.
- This is not a marketplace.
- Only admins can add products and create auctions.
- Users must register/login before bidding.
- Users must complete profile and delivery details before bidding.
- Required user details:
  - full name
  - country
  - city
  - address
  - phone number
- Stack:
  - Next.js (App Router, Server Actions)
  - TypeScript
  - Tailwind CSS
  - shadcn/ui
  - Supabase Auth
  - Supabase Database (PostgreSQL with custom transaction functions and triggers)
  - Supabase Storage (for product images)
  - Supabase Realtime (for live bid synchronization)
  - Vercel deployment
- Do not use Prisma.
